# Прогноз продаж на неделю

Взял дневные продажи категории FOODS в магазине Walmart CA_1. Сравнил CatBoost с прогнозом по тому же дню прошлой недели. Для каждой из последних 12 недель прогнозировал сразу семь дней по данным, известным до её начала.

С 29 февраля по 22 мая 2016 года средняя абсолютная ошибка снизилась с **264,8 до 219,5 штуки в день** (на 17,1%). CatBoost оказался точнее в 9 из 12 недель.
